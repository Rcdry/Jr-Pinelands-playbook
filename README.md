# Junior Pinelands Playbook

A mobile-friendly football training app for Pinelands Wildcats players.

## Current features
- Player/codename check-in
- Multi-position selection
- Playbook rotation across the loaded verified play names
- Defensive-front recognition
- Offensive-line technique coaching
- XP, streaks, shields, coverage tracking
- Local profile saving with browser localStorage
- Responsive iPad/phone/desktop layout
- Wildcat-inspired green/gold styling

## Important
Exact football assignments are intentionally not invented. The current build rotates the verified play names and trains defensive-front/technique recognition. The coach-issued assignment matrix can be added next so each selected position is graded against the actual playbook.
